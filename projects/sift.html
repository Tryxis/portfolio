Sift

Steam backlog tracker

A personal Steam library tracker for working through a growing backlog. Sort games into status categories, see playtime, Steam review scores and HowLongToBeat estimates alongside each game.

Filter your library, save named views, switch between cards and a spreadsheet-style table, and check summary metrics. Sign in with Steam to manage your own library, or look up anyone else’s read-only.

Powered by Steam Web API. Authenticated with OpenID 2.0.

Web React ASP.NET Core 8 Postgres Live

The demo may take up to a minute to start if it has gone idle.
