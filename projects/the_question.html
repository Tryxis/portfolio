The Question

Interface-based quiz game

Test your popular culture knowledge in rounds of multiple choice questions.

Game
Play Me View Repo

Build notes

Questions are data, not code

Each question is a Unity ScriptableObject holding the prompt, four answers and the index of the right one. Writing a new round is filling in assets in the editor — no programmer needed, and no rebuild to change a typo in an answer.

One state machine drives the round

The quiz script owns the whole cycle: draw a random unasked question, run the timer, lock the buttons on an answer, reveal the correct one, advance the progress bar, and hand over to the end screen when the pool runs dry.
